# BidWin Brand Guidelines

## Logo Files
- **Primary Logo**: `bidwin-logo.svg` (icon + wordmark, light background)
- **Dark Background**: `bidwin-logo-dark.svg` (icon + wordmark, dark background)
- **Icon Only**: `bidwin-icon.svg` (for favicon, mobile, sidebar)

## Color Palette

### Primary Colors
| Name | Hex | RGB | Usage |
|------|-----|-----|-------|
| **Blue-600** | `#2563EB` | rgb(37, 99, 235) | Primary brand color, CTAs, links |
| **Blue-500** | `#3B82F6` | rgb(59, 130, 246) | Gradient start, hover states |
| **Blue-400** | `#60A5FA` | rgb(96, 165, 250) | Accent on dark backgrounds |

### Neutral Colors
| Name | Hex | RGB | Usage |
|------|-----|-----|-------|
| **Slate-900** | `#0F172A` | rgb(15, 23, 42) | Dark sidebar, dark UI |
| **Slate-800** | `#1E293B` | rgb(30, 41, 59) | "Bid" text on light bg |
| **White** | `#FFFFFF` | rgb(255, 255, 255) | "Bid" text on dark bg |

## Typography
- **Headlines/UI**: DM Sans (Bold, 700)
- **Body**: Source Serif 4 (Regular, 400)
- **Wordmark**: System UI stack with -1px letter-spacing

## Logo Usage

### Minimum Size
- Icon: 24x24px minimum
- Full logo: 120px width minimum

### Clear Space
- Maintain padding equal to the height of the "B" icon around the logo

### Don'ts
- Don't rotate or skew the logo
- Don't change the colors outside the brand palette
- Don't add effects like drop shadows or glows
- Don't stretch or distort proportions
